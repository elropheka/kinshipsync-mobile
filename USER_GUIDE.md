# KinshipSync Mobile App - User Guide

## Overview
KinshipSync is your ultimate event planning and family connection app. It helps you organize reunions, events, and stay connected with family and friends in one central platform.

## Getting Started

### 1. Account Creation & Authentication
- **Landing Screen**: Welcome screen showcasing app features
- **Sign Up**: Create account with email/password, Google, or Apple Sign-In
- **Sign In**: Access existing account with multiple authentication options
- **Profile Setup**: Add profile picture, personal information, and preferences
- **Password Recovery**: Reset forgotten passwords via email

### 2. Main Dashboard
- **Welcome Screen**: Personalized greeting with your name
- **Upcoming Events**: Quick view of your next events
- **Recent Activities**: Latest notifications and updates
- **Search**: Find events quickly
- **Notifications**: Stay updated with real-time alerts

## Core Features

### 🎉 Event Management

#### Creating Events
- **Event Details**: Name, description, date, time, location
- **Visibility Settings**: Private or public events
- **Guest Management**: Invite specific users or make it open
- **Theme Selection**: Choose from available event themes
- **Website Creation**: Generate event websites automatically

#### Event Organization
- **Event List**: View all your events (upcoming/past)
- **Event Details**: Comprehensive event information
- **Edit Events**: Modify event details anytime
- **Event Categories**: Organize by type or purpose

### 👥 Guest Management

#### Guest Invitations
- **Invite Guests**: Add family and friends to events
- **RSVP Tracking**: Monitor who's attending
- **Guest Status**: Track invited, accepted, declined, pending
- **Reminders**: Send RSVP reminders to guests
- **Guest Preferences**: Collect dietary restrictions and preferences

#### RSVP Management
- **RSVP Responses**: Accept/decline invitations directly
- **Status Filtering**: Filter guests by response status
- **Bulk Actions**: Manage multiple guests at once
- **Guest Communication**: Send messages to specific guests

### 💬 Communication & Chat

#### Event Messaging
- **Group Chats**: Communicate with all event participants
- **File Sharing**: Send photos, documents, and media
- **Emoji Reactions**: Express yourself with emojis
- **Message Types**: Text, images, documents, RSVP responses
- **Real-time Updates**: Instant message delivery

#### Chat Features
- **Message History**: Access all previous conversations
- **Media Gallery**: View shared photos and files
- **Conversation Settings**: Manage chat preferences
- **New Chat**: Start conversations with event participants

### 🏢 Team & Family Management

#### Team Creation
- **Create Teams**: Form family or friend groups
- **Team Dashboard**: Central hub for team activities
- **Family Tree**: Visual representation of family connections
- **Add Members**: Invite family members to teams
- **Team Collaboration**: Work together on events and planning

### 🛍️ Vendor Management

#### Vendor Discovery
- **Browse Vendors**: Find vendors by category
- **Vendor Details**: View vendor information and services
- **Vendor Selection**: Choose vendors for your events
- **Category Filtering**: Filter by service type
- **Vendor Reviews**: Read and leave reviews

### 📋 Event Planning Tools

#### Task Management
- **Create Tasks**: Assign and track event planning tasks
- **Task Categories**: Organize by planning area
- **Progress Tracking**: Monitor completion status
- **Team Assignments**: Delegate tasks to team members

#### Budget Planning
- **Budget Creation**: Set event budgets
- **Expense Tracking**: Monitor spending
- **Budget Categories**: Organize by expense type
- **Payment Tracking**: Record payments made

#### Scheduling
- **Event Timeline**: Plan event schedule
- **Time Management**: Allocate time for activities
- **Schedule Conflicts**: Identify and resolve conflicts
- **Reminders**: Set important deadlines

#### Ideas & Themes
- **Idea Submission**: Share event ideas
- **Theme Selection**: Choose event themes
- **Collaborative Planning**: Get input from team members
- **Theme Customization**: Personalize themes

### 🌐 Event Websites

#### Website Creation
- **Auto-Generated Sites**: Create websites automatically
- **Custom Content**: Add event details and information
- **Publishing**: Make websites live for guests
- **Website Updates**: Modify content as needed

### 📱 User Experience Features

#### Notifications
- **Real-time Alerts**: Get notified of important updates
- **Notification Types**: Event invites, RSVP updates, messages, tasks

#### Settings & Preferences
- **Profile Management**: Update personal information
- **Privacy Settings**: Control visibility and sharing

- **Event Search**: Find events by name, location, or description

## Navigation Structure

### Main Tabs
- **Home**: Dashboard with overview and quick actions
- **Events**: Event management and creation
- **Teams**: Family and team management
- **Profile**: Personal settings and account management

### Event-Specific Navigation
- **Events List**: All your events
- **Guests**: Guest management and RSVPs
- **Messages**: Event communication
- **Tasks**: Event planning tasks
- **Budget**: Financial planning
- **Schedule**: Timeline management
- **Themes**: Event styling
- **Website**: Event website management

## Key User Flows

### 1. Creating Your First Event
1. Tap "Add new event" from Events tab
2. Fill in event details (name, date, location)
3. Select visibility and invite guests
4. Choose a theme
5. Create event website
6. Start planning with tasks and budget

### 2. Managing RSVPs
1. Go to Events → Select Event → RSVPs
2. View guest list and response status
3. Send reminders to pending guests
4. Update guest preferences
5. Track attendance numbers

### 3. Team Collaboration
1. Create or join a team
2. Add family members
3. Collaborate on events
4. Share tasks and responsibilities
5. Communicate through team chats

### 4. Vendor Selection
1. Browse vendor categories
2. View vendor details and reviews
3. Select vendors for your event
4. Contact and book services
5. Track vendor progress

## Tips for Best Experience

### Event Planning
- Start planning early to allow time for RSVPs
- Use the task management system to stay organized
- Set up event websites to share information easily
- Use team collaboration features for group planning

### Communication
- Enable notifications to stay updated
- Use the chat feature for quick communication
- Share important documents through the messaging system
- Set up regular check-ins with your team

### Organization
- Use the search feature to find events quickly
- Filter events by status to focus on what's important
- Keep your profile updated for better team collaboration
- Use themes to make events more engaging

## Support & Help

### Account Issues
- Use password recovery for forgotten passwords
- Contact support through the app settings
- Delete account if needed through account settings

### Technical Support
- Check notification settings if not receiving alerts
- Ensure app permissions are granted for camera and storage
- Update app regularly for best performance
